AI SmartEat 個人飲食決策管理 Web App

多模態 AI 營養秒辨識 · 菜單與周邊地圖推薦 · 個人化健康目標管理

專為追求健康與體態目標者打造的 AI 飲食決策系統。結合多模態視覺辨識與地理定位演算法，拍照即可秒算熱量與三大營養素並追蹤長週期趨勢；更可解析餐廳菜單或定位探索周邊店家，智慧推薦兼顧美味與營養目標的最佳組合。

1. 餐點拍照 AI 辨識

自動分析熱量、蛋白質、碳水等營養素，生成每日/週/月飲食總表。

2. 菜單智慧組合推薦

上傳想吃餐廳的菜單或 Google Map 位置，AI 量身推薦符合目標的餐點。

3. 周邊美食定位篩選

新地點即時定位搜尋，自動為您篩選兼顧飲食目標的周邊餐廳與餐點。

使用 API / 技術：
Multimodal AI Vision API Google Maps & Places API Geolocation API Vercel Cloud Deployment Fetch / RESTful API
應用場景：

外食族日常熱量與營養控管、健身增肌減脂精準點餐決策、出差旅遊快速探索健康餐廳。
