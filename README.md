### 🌟 核心個人專題 · 旗艦作品 (Flagship Project)
* **[AI SmartEat 個人飲食決策管理 Web App](https://smart-eating-drab.vercel.app)**
  * **簡介**：專為追求健康與體態目標者打造的 AI 飲食決策系統。結合多模態視覺辨識與地理定位演算法，拍照秒解熱量營養素並追蹤長週期趨勢；更可解析菜單或地圖定位探索周邊店家，智慧推薦最佳餐點組合。
  * **核心功能**：
    1. 📸 餐點拍照 AI 辨識熱量、蛋白質、碳水等營養素，生成日/週/月飲食總表。
    2. 📋 上傳餐廳菜單或 Google Map 位置，量身推薦符合目標的餐點。
    3. 📍 新地點即時定位搜尋，自動篩選兼顧飲食目標的周邊餐廳與餐點。
  * **使用技術**：Multimodal AI Vision API, Google Maps & Places API, Geolocation API, Vercel Deployment, Fetch / RESTful API。

## 💻 本地預覽 (Local Development)

若要在本機預覽此作品集：

```bash
# 1. 複製專案
git clone https://github.com/MarkVee23/MyWorks.git

# 2. 進入資料夾
cd MyWorks

# 3. 啟動本地伺服器 (以 Python 為例)
python3 -m http.server 8080

# 4. 在瀏覽器打開
open http://localhost:8080/
```

或直接以瀏覽器雙擊打開 `index.html` 即可瀏覽！
